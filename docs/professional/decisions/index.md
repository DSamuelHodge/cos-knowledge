# Decisions

## Description
Decision log: what was decided, why, and consequences.

## Purpose
Decisions and rationale stay recoverable — no re-litigating from memory.

## Content overview
One page per decision: `YYYY-MM-DD-slug.md`.

## Formatting guidelines
Frontmatter: id, type=decision, updated, status. Format: context, decision, alternatives, consequence.

## Recommended tools
push, kaneo

Per-page contract: `id`, `type`, `category`, `updated` (+ `status`, `tags` as needed).
