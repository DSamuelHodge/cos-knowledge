# Workflows

## Description
Procedures and SOPs — repeatable, improving how-to knowledge.

## Purpose
Any procedure worth doing twice becomes a searchable document.

## Content overview
One page per workflow: steps, triggers, ownership, tools.

## Formatting guidelines
Frontmatter: id, type=workflow, updated. Ordered steps, callouts for cautions.

## Recommended tools
push, macro

Per-page contract: `id`, `type`, `category`, `updated` (+ `status`, `tags` as needed).
