# Projects

## Description
Professional projects: goals, owners, status, next actions.

## Purpose
One source of truth per project; progress visible at a glance.

## Content overview
One page per project with milestones; link to kanban board where used.

## Formatting guidelines
Frontmatter: id, type=project, updated, status (draft|current|archive).

kaneo, macro
